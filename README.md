 HABIT - Protótipo de Wireframes Web & Mobile

Projeto de prototipagem e desenvolvimento de wireframes responsivos para a plataforma **HABIT**, cobrindo fluxos de navegação pública, blog, painel administrativo e autenticação.

Sobre o Projeto:

Este repositório contém a implementação em **HTML** e **CSS (BEM / CSS Variables)** das telas do projeto HABIT, adaptadas para layouts responsivos com foco em boas práticas.

---

## 📱 Telas Desenvolvidas

* **Tela 01:** Página Inicial / Feed Principal
* **Tela 02:** Detalhe da Postagem / Artigo
* **Tela 03:** Listagem de Páginas / Destaques
* **Tela 04:** Plano de Assinatura
* **Tela 05:** Painel Admin - Categorias
* **Tela 06:** Painel Admin - Criar Post
* **Tela 07:** Painel Admin - Escolhas do Editor
* **Tela 08:** Painel Admin - Gestão de Usuários
* **Tela 09:** Painel Admin - Fila de Revisão
* **Tela 10:** Painel Admin - Fila de Comentários
* **Tela 11:** Resultados da Busca
* **Tela 12:** Tela de Login (Entrar)
* **Tela 13:** Tela de Cadastro (Criar Conta)
* **Tela 14:** Perfil do Usuário e Suas Postagens

---

## 🛠️ Tecnologias Utilizadas

* **HTML:** Semântica e acessibilidade.
* **CSS:** Flexbox, CSS Grid, Variáveis CSS (`variables.css`).
* **Arquitetura CSS:** Organização BEM.
